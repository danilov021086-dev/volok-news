# volok-news — лента новостей для кабинета ВОЛОК

Бот собирает новости про биткоин и майнинг, отбирает те, что касаются
владельца фермы, просит у модели одну фразу о влиянии на доход и
складывает всё в `news.json`. Личный кабинет ВОЛОК читает этот файл и
показывает ленту на вкладке «Обзор».

Репозиторий публичный намеренно: здесь только код бота и сам
`news.json`. **Ключей, паролей и чьих-либо данных здесь нет и быть не
должно** — ключ модели живёт в секретах GitHub Actions.

## Что внутри

| Файл | Зачем |
|---|---|
| `bot/fetch_news.py` | главный: читает RSS, отбирает, снимает дубли, зовёт разбор, пишет `news.json` |
| `bot/keywords.py` | словарь отбора и меток — правится чаще всего остального |
| `bot/ai.py` | разбор заголовка моделью: строгий JSON и четыре запрета |
| `bot/market.py` | курсы, сложность, хешрейт сети, хешпрайс — у каждого числа источник и время |
| `.github/workflows/news.yml` | запуск раз в 30 минут |
| `news.json` | результат; его и читает кабинет |

## Откуда берутся новости

* ForkLog — `https://forklog.com/feed`
* Bits.media — `https://bits.media/rss2/`

Берутся **только заголовок, ссылка, дата и название источника**. Текст
статей и картинки бот не скачивает и не хранит.

Третий источник можно добавить в `SOURCES` в `bot/fetch_news.py` —
но только с официальным RSS. Парсить чужой сайт без ленты мы не будем.

## Что попадает в ленту

Заголовок должен получить хотя бы одну метку:

| Метка | Про что |
|---|---|
| `mine` | майнинг, асики, хешрейт, сложность, электричество для ферм |
| `btc` | биткоин: цена, халвинг, крупные держатели |
| `ru` | Россия: законы, налоги, проверки, тарифы |

Слова — в `bot/keywords.py`. Там же список исключений: NFT, мем-коины,
метавселенные и прочее, что владельцу фермы не новость.

Дубли снимаются дважды: по ссылке (без utm-хвостов) и по похожести
заголовков — два источника часто пишут об одном и том же разными
словами.

Хранится 200 последних. Время — **московское**.

## Разбор моделью

Для каждой НОВОЙ новости (уже разобранные не переспрашиваются) модель
получает только заголовок, источник и дату и отвечает строго:

```json
{"impact": "plus|minus|risk|neutral", "text": "одна фраза до 140 знаков"}
```

* `plus` — доход фермы скорее вырастет;
* `minus` — скорее упадёт;
* `risk` — прямого влияния нет, но есть угроза;
* `neutral` — на доход не влияет.

Ответ проверяется: неизвестный `impact`, пустой или слишком длинный
`text`, совет покупать или продавать — всё это **отказ**. При отказе
пишется `ai: null` и причина в журнал прогона. Шаблонная оценка вместо
настоящей не подставляется никогда: выдуманный разбор хуже отсутствия
разбора.

### Ключ модели

Без ключа бот работает целиком, только у новостей стоит `ai: null`.
Чтобы включить разбор:

1. Получить ключ на `console.anthropic.com` (раздел API Keys).
2. В этом репозитории: **Settings → Secrets and variables → Actions →
   New repository secret**, имя `VOLOK_AI_KEY`, значение — ключ.
3. По желанию: переменная `VOLOK_AI_MODEL` (по умолчанию
   `claude-haiku-4-5-20251001`) и `VOLOK_AI_MAX` — сколько заголовков
   разбирать за один прогон (по умолчанию 25, предохранитель от
   неожиданного счёта).

Секрет виден только Actions; в `news.json` и в логи он не попадает.

## Блок `market`

Рядом с новостями лежат числа, по которым считается доход:

* BTC/USDT — Bybit, ряды за 1 час, 24 часа и 30 дней;
* USDT/₽ — CoinGecko, те же три окна;
* сложность и хешрейт сети — mempool.space, запасной blockchain.info;
* хешпрайс — рублей за терахеш в сутки, считается из сложности, цены и
  курса.

У каждого числа стоит источник и время снятия. Источник не ответил —
значение `null`, плюс время последнего удачного снятия и текст ошибки.
Ноль вместо неизвестного здесь запрещён.

## Запустить руками

```bash
python bot/fetch_news.py          # без ключа — соберёт всё, кроме разбора
VOLOK_AI_KEY=... python bot/fetch_news.py
```

В GitHub: вкладка **Actions → Лента новостей ВОЛОК → Run workflow**.
